# Identidade visual — Lex Detetive

Símbolo: **lupa dourada com ramo de oliveira** dentro da lente (investigação + justiça/paz), sobre fundo azul-escuro.

| Arquivo | Uso |
|---|---|
| `logo-mark.svg` | Ícone/símbolo vetorial (app, favicon, relatórios) |
| `logo-horizontal.svg` | Logotipo horizontal para fundo claro |
| `logo-horizontal-dark.svg` | Logotipo horizontal para fundo escuro |
| `lex-detetive.icns` | Ícone do macOS |
| `png/lex-detetive-icone-{16…1024}.png` | Ícone em PNG (16, 32, 48, 64, 128, 180, 192, 256, 512, 1024 px) |
| `png/lex-detetive-horizontal.png` | Logotipo horizontal em PNG |

## Cores

| Nome | Hex |
|---|---|
| Azul Escuro | `#0B1F3A` |
| Azul Jurídico | `#163E7A` |
| Dourado | `#C9A227` |
| Cinza Claro | `#F4F6F8` |
| Branco | `#FFFFFF` |

Tipografia: Inter (ou Helvetica/Arial como alternativa).
